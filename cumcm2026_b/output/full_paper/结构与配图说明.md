# 全文结构与配图说明

## 参考论文的章节功能

本次结构依据本地保留的 A23100070049《WLAN网络信道接入机制建模》和 D23100060041《区域碳排放量影响因素分析及双碳目标分析》。两篇实际属于 2023 年研究生数学建模竞赛；借鉴论证组织方式，不照搬其封面、篇幅和参赛信息。前者的四问递进结构与本题更接近，作为主要结构参照。本次未重新确认原 GitHub 仓库地址，不凭文件名补写仓库来源。

| 范文部分 | 实际承担的作用 | 本文对应写法 |
|---|---|---|
| 摘要 | 总述方法，再逐问交代模型、求法、数值和结论 | 一段背景加四问结果，明确仿真与演练性质 |
| 问题重述 | 压缩题意，列清四问交付 | 只保留影响模型的观测、动作和全清要求 |
| 假设和符号 | 说明简化依据，统一语言 | 分开题面条件与自建模拟器的分布假设 |
| 问题分析 | 在公式前解释难点及解题路线 | 从单源几何递进到未知源数与定向盲区 |
| 基本模型 | 建立各问共享的关系，减少后文重复 | 示向可行集、动作计时、频道状态、评价口径 |
| 每问模型与求解 | 说明该问新增条件怎样改变模型，给出可执行求法 | 几何算法、第二点枚举、联合调度、双风险停止 |
| 每问仿真验证 | 给定输入、输出数字，再解释机制 | 构造算例、独立仿真、官方演练分别落表 |
| 模型评价 | 从实际结果指出优点和失败条件 | 概率停止残余风险、离散近似、官方分布差异 |
| 附录 | 让读者能复现，而不是替正文解释方法 | 伪代码、代码入口、数据来源、正式测试补填项 |

## 采用的论证主线

在有界示向误差下，以可行区域保存定位不确定性，以完整动作耗时评价搜索与跨源服务路线，再用覆盖信息推断未知剩余源；独立仿真和官方演练检验效率，同时展示概率提前停止的漏源代价。

正文顺序：摘要；1 问题重述；2 假设和符号；3 总体分析；4 基本模型；5 问题一；6 问题二；7 问题三；8 问题四；9 灵敏度与消融；10 评价与结论；参考文献；实现附录。没有采用 Nature 英文论文格式，写作技能仅用于保证论证和证据一致。

## 数字采用规则与关键纠正

1. “最优”指已验证候选中的条件最优，必须连同清除率、测试分布、样本数和时间口径出现。各模型分别报告，不把多个模型混合平均。
2. 题面每局平均定位清除时间为 T/C。多局主统计用逐局 T/C 的算术平均；同时单列 ΣT/ΣN 便于说明按真实源加权的工作量。这两项不互相替代。
3. 第三问要求全清，第四问沿用第三问条件。98% 是已有研究的速度取舍，不是题面规定。source-98 全部保留为速度与可靠性实验，不能包装为全清解。
4. Q4 conservative 在旧混合源 500 局中仍有一局未全清；正文直接报告，不能写“确保所有源被清除已得到证明”。
5. 官方程序运行时间采用 official_statistics.program_run_duration_ms / 1000；本地 wall_time_s 只用于本地性能说明。
6. 每题三次正式测试表保留原四列。当前发现的 summary 都是演练，正式数据待填，不能用演练案例编码顶替。
7. 题目程序现实时间上限是进入后 20 分钟，且受 25 分钟总窗口约束；100 s 是此前内部性能目标，不能写成官方限制。
8. Q1 接收圆盘裁剪存在于 build_q12_assets.feasible_region，在线 localization_polygon 仅裁剪目标圆与示向扇形。正文分别描述。
9. Q2 的“最坏”来自有限源位置和三个误差样本的枚举，不宣称连续区域的全局最优。内接多边形也不是严格外包络。

## 术语统一

| 统一用语 | 定义 |
|---|---|
| 定位可行域 | 与已获得示向约束一致的位置集合 |
| 定位区域直径 D | 区域内任意两点距离的最大值 |
| 最小包围圆半径 R* | 覆盖整个定位区域的最小圆半径 |
| 全清率 | 全部源被清除的测试局数占比 |
| 源级清除率 | 累计清除数除以累计真实源数 |
| 平均定位清除时间 | 按题面定义的 T/C |
| 虚拟时间 | 模拟器累计的动作时间 |
| 程序运行时间 | 官方统计的现实时间 |
| 联合策略 joint | Q3 当前正式运行器默认的联合搜索与追踪策略 |
| source-efficient v2 | 源级风险 0.04、任一剩余源风险 0.10 的双风险配置 |
| source-98 | 源级风险 0.04、任一剩余源风险 0.25 的速度配置 |
