# 研究事实与边界

1. 区域是半径 1800 m 的圆；信号接收半径为 1000--1500 m；问题 4 同时含全向源与覆盖角 180° 的定向源。
2. 方位误差上界为 1°；测量、换频、精确定位、清除和移动均计入题目虚拟时间。
3. 源总数只知位于 10--16，官方 API 不返回真实总数；程序只能根据观测历史决定停止。
4. 清除完整率优先于耗时。报告必须同时给出源级清除率与整局全清率。
5. 全知开放路线只作为物理下界，不能称为合法在线策略成绩。
6. 500+500 独立场景使用固定种子集合，基线与候选逐场景配对。
7. `balanced` 档的源级清除率接近 100%，但整局全清率不是 100%；不得写成“完全保证”。
8. 神经网络只能缩短在线计算墙钟或逼近更好的可观测策略，不能直接减少题目规定的移动和交互时间。
9. 单决策反事实实验给出的上限包含第一步对称性造成的不可学习部分；不能把 13.9% 的全知改善全部当成神经网络可实现收益。
