# 论证图

- 核心矛盾：未知源总数和定向漏检要求继续搜索，但继续搜索的移动与全频道测量又主导总耗时。
- 研究问题：如何在不使用隐藏真值的前提下，把“漏掉尚未出现源”的概率显式纳入停止与路线决策，并给出可审计的速度—可靠性选择？
- 中心论点：采用风险约束的信念覆盖、联合清除路线和置信触发的几何估计，可形成比固定覆盖路线更有效的 Pareto 策略；0.998 与 0.97 应作为不同可靠性档位呈现。
- 支撑 1：动作分解证明搜索扫描占测量大头，停止后验是混合源耗时的主要杠杆。
- 支撑 2：两方位误差分析支持“圆心只用于路线估价、质心清除只在半径≤75 m 时触发”的职责分离。
- 支撑 3：500+500 配对实验给出改善、置信区间与失败频率。
- 反论点：更低阈值可能漏源；回应是同时保留 conservative 档并公开整局全清率。
- 局限：代理仿真与官方分布可能存在偏差；必须以官方演练作域校准，不能将代理结果写成正式成绩。
- 最终落点：推荐演练/竞速使用 balanced，正式提交前按风险偏好在 conservative 与 balanced 间选择。
